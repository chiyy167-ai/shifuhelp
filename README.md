# 保利管道 · 师傅上门（四端演示 PWA）

单页演示封装为可在 **Android / iOS** 主屏幕打开的 Progressive Web App。

顶部切换四端：**客户端 · 水工端 · 司机端 · 管理端**（状态多端同步）。

## 在线演示

https://chiyy167-ai.github.io/shifuhelp/

## 本地预览

```bash
npx --yes serve .
```

勿用 `file://`，Service Worker 需要 HTTP(S)。

## 四端职责（演示）

| 端 | 要点 |
|----|------|
| 客户端 | 预约下单、支付、看配送/进度、确认增项、验收 |
| 水工端 | 抢单或接受指派、到场签到、扫码核销、材料签收、施工/试压 |
| 司机端 | 接运单、仓库装车、同城配送、300米围栏送达、异常上报 |
| 管理端 | **派单**（水工/司机）、配送监控、渠道/经营看板 |

### 派单与配送协同

1. 客户支付后生成服务单 + 材料运单  
2. 管理端可 **抢单 / 指派** 水工与司机（派单页可切换策略）  
3. 司机：接单 → 装车 → 同城配送 → 围栏内确认送达  
4. 水工签收材料后才能开工；异常同步到管理端预警  

## 手机安装

- **Android（Chrome）：** 菜单 → 安装应用 / 添加到主屏幕  
- **iOS（Safari）：** 分享 → 添加到主屏幕
